# Участие в разработке Rekogram Desktop

Спасибо за интерес к участию в развитии проекта Rekogram Desktop!

## Основные правила

1. **Сохранение стабильности**: любые изменения не должны нарушать базовую функциональность официального клиента Telegram и протокола MTProto.
2. **Безопасность**:
   - Никогда не коммитьте секретные ключи, токены ботов, личные пароли или реальные Telegram API credentials (`api_id`, `api_hash`).
   - Идентификатор создателя (`OWNER_ID`) используется только для визуального оформления (значка в интерфейсе) и не должен влиять на права доступа или безопасность.
3. **Стиль кода**:
   - Используйте C++20.
   - Следуйте соглашениям форматирования Telegram Desktop (отступы табуляцией, CRLF-окончания строк на Windows, без UTF-8 BOM).
   - Разбивайте коммиты логически по префиксам (`feat:`, `fix:`, `rebrand:`, `docs:`).
4. **Структура форка**:
   - Новые специализированные компоненты Rekogram размещаются в папке `Telegram/SourceFiles/rekogram/` либо в соответствующих подпапках `settings/sections/`.
   - Не создавайте дублирующие экраны существующих настроек Telegram — расширяйте функционал через раздел «Настройки Rekogram».

## Сборка и тестирование

Сборка осуществляется аналогично оригинальному проекту Telegram Desktop через CMake и Visual Studio (на Windows) или Docker-окружение (на Linux). Подробные инструкции по подготовке окружения смотрите в `docs/building-win.md` и `docs/building-linux.md`.
